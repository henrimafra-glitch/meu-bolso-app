# CONSTITUIÇÃO DO PROJETO "MEU BOLSO"
Versão: 1.0.0 · Março de 2026

## 1. Princípios Inegociáveis (Core Tenets)

1. **CUSTO ZERO PERMANENTE (ALWAYS FREE)**:
   - O projeto deve ser desenvolvido e mantido com ferramentas, serviços e soluções 100% gratuitas ou de código aberto.
   - Nenhuma biblioteca ou serviço com armadilha de cartão de crédito ou trial temporário é aceito.

2. **ISOLAMENTO & PRIVACIDADE FAMILIAR (RLS FIRST)**:
   - Toda tabela contendo dados do usuário no PostgreSQL DEVE possuir Row Level Security (RLS) ativado.
   - Um usuário só pode visualizar ou manipular registros associados ao seu núcleo familiar verificado.

3. **SOBERANIA DA ESPECIFICAÇÃO (SDD)**:
   - O código é detalhe de implementação da especificação.
   - Em caso de divergência ou ambiguidade, corrija a especificação (`spec.md`) antes de alterar o código.

4. **EXPERIÊNCIA DUAL RESPONSIVA (MOBILE NATIVO + DESKTOP EXECUTIVO)**:
   - Em smartphones (< 1024px): Sensação de aplicativo nativo (Bottom Nav fixa, gavetas deslizantes, toque confortável para polegar).
   - Em computadores (>= 1024px): Painel executivo com Sidebar retrátil, tabelas densas ordenáveis e filtros instantâneos.

5. **RIGOR TIPOGRÁFICO E VISUAL FINTECH**:
   - Paleta sóbria (Slate neutro, Teal acento #0D9488, Verde discreto receitas #10B981, Carmim atenuado despesas #E11D48).
   - PROIBIDO o uso de emojis de IA (robôs, foguetes, faíscas) e travessões decorativos repetitivos.
